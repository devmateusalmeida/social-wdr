# social-wdr

Publicador automático do social media da WDR (fase de teste, conta
@intemocionalmasculina).

- `imagens/`: artes aprovadas, num endereço público (GitHub Pages) pra Meta
  baixar na hora de postar
- `fila/`: posts aprovados de cada cliente, com data, hora e situação
  (aguardando, publicando, publicado, erro)

O token de cada Instagram fica guardado como segredo do GitHub, nunca nos
arquivos daqui. Ficha, voz e material do cliente ficam fora deste repositório.
